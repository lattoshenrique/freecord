# Room URLs are secret by design: the unguessable slug in /r/<slug> IS the
# access credential, so an indexed room is a world-readable room. Every agent
# below is disallowed from /r/, and that rule is repeated per-agent rather
# than left to a wildcard, because a crawler that matches its own name-block
# ignores the * block entirely.
#
# Note this file is a request, not a control. The enforcing layer is the
# X-Robots-Tag header on /r/ responses; see docs/architecture.md.

User-agent: *
Allow: /$
Allow: /community
Disallow: /r/
